# Python Learning

Beginner Python projects I wrote to practice the fundamentals: user input, conditionals, loops, counters and the `random` module.

## Projects

| Project | File | Concepts practiced |
|---|---|---|
| Computer quiz | [`quiz_game.py`](quiz_game.py) | Input, string comparison, scoring, percentages |
| Number guesser | [`number_guesser.py`](number_guesser.py) | Input validation, `while` loops, `random.randint` |
| Rock, paper, scissors | [`rock_paper_scissors.py`](rock_paper_scissors.py) | Game loop, lists, win/loss counters |
| Choose your own adventure | [`choose_your_own_adventure.py`](choose_your_own_adventure.py) | Nested conditionals, branching logic |

## Run a project

Requires [Python 3](https://www.python.org/downloads/).

```bash
python quiz_game.py
```

Replace `quiz_game.py` with any file from the table above.
